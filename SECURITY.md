# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| `1.0.x` | :white_check_mark: |

## Verifying Release Binaries

Always verify downloaded `.ipa` and `.apk` files against the companion `.sha256` checksum published on the [GitHub Releases](https://github.com/Muhammad-Favel/FlowDownload-Releases/releases) page before installing.

## Reporting a Vulnerability

If you discover a security vulnerability in FlowDownload, its release feed (`source.json`), or the release site:

1. **Do not** open a public issue with exploit details.
2. Report it privately using GitHub's **Security Advisories** (*Security* -> *Advisories* -> *Report a vulnerability*) on this repository.
3. Include a clear description of the issue, affected version/component, and steps to reproduce.

We will acknowledge reports and work on a fix as promptly as possible.
